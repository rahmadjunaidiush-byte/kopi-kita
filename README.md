# Kopi Kita — Teman Cerita

Website statis untuk Kopi Kita dengan halaman beranda, menu, promo, ulasan, dan informasi kedai.

## Jalankan secara lokal

- Windows: jalankan `run.bat`, atau pilih task **Run Kopi Kita on localhost** di VS Code.
- macOS/Linux: jalankan `./run.sh` dari folder proyek.
- Buka <http://localhost:8000>.

## Halaman

- `index.html` — beranda dan testimoni contoh
- `menu.html` — menu dengan keranjang dan pemesanan melalui WhatsApp
- `promo.html` — ide paket promo
- `tentang.html` — informasi Kopi Kita
- `ulasan.html` — contoh ulasan pelanggan

Harga menu, promo, dan testimoni saat ini merupakan konten contoh. Perbarui dengan informasi resmi sebelum dipublikasikan untuk pelanggan.
